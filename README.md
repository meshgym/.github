# MeshGym — .github

Welcome to the **MeshGym** community health and configuration repository.

This repo contains GitHub-related configuration files (issue templates, pull request templates, workflows, and other community standards) for all products related to **MeshGym** — your go-to destination for premium gym mesh products.

## About MeshGym

[MeshGym](https://meshgym.com/) offers a range of high-quality gym mesh products designed for performance, comfort, and durability. Whether you're outfitting a home gym or a commercial fitness facility, MeshGym has the products you need.

🌐 **Website:** [https://meshgym.com/](https://meshgym.com/)

## Repository Contents

This `.github` repository provides shared defaults for all MeshGym repositories, including:

- **Issue templates** — standardised templates for bug reports and feature requests
- **Pull request templates** — consistent PR checklists across projects
- **GitHub Actions workflows** — reusable CI/CD automation
- **Community guidelines** — code of conduct, contributing guide, and security policy
